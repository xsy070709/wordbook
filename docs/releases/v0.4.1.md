# 生词本 0.4.1

此补丁版本改进数据迁移入口和纸质复习体验，适用于 Android 6.0 及以上系统。

## 改进

- 对调导入和导出图标，使图标方向与数据流向一致
- PDF 打印内容左侧增加自适应留白，避免文字紧贴边界
- 打印时可同时选择多个分册，合并生成一个文档
- 保留打印全部生词、仅打印原词或同时打印释义的选项
