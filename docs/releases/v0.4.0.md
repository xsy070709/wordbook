# 生词本 0.4.0

此版本新增生词本迁移、批量操作与纸质复习能力，适用于 Android 6.0 及以上系统。

## 新功能

- 记录最近查过的单词，方便快速重新查询
- 以易读的 JSON 文件导出完整生词本
- 从符合格式规范的 JSON 文件合并导入分册和生词
- 导入前完整校验文件，避免失败时只写入部分数据
- 打印所有生词或当前选中的分册
- 打印时可选择仅保留英文原词，或同时包含释义

JSON 文件结构及字段规则见项目中的 `docs/IMPORT_EXPORT_FORMAT.md`。
