# 生词本 0.3.0

这是生词本的首个公开版本，适用于 Android 6.0 及以上系统。

## 功能

- 完全离线的英汉词典，内置 768,739 条带中文释义的 ECDICT 词条
- 查词、前缀联想、收藏和按字母排序
- 生词本支持英文、中文释义和批注检索
- 自定义分册、加入日期和个人批注
- 手动录入词库中没有的单词或短语
- 从其他应用选中文本后，通过“处理文本”或“分享”进入生词本
