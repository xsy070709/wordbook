# 生词本 0.4.3

此版本完善搜索历史，并增加 GitHub Release 更新提醒，适用于 Android 6.0 及以上系统。

## 新增与改进

- 搜索历史首页展示最近20条，可继续查看最近100条。
- 历史记录显示精确到分钟的查阅时间，支持逐条删除和确认后清空。
- 仅在明确提交查词、选择联想、点击历史、外部查词或收藏时记录有效搜索，避免拼写过程留下无关词条。
- 应用进程启动时检查一次 GitHub 最新正式 Release。
- 发现新版时展示更新说明并发送系统通知，可选择稍后处理或忽略该版本。
- 更新入口打开项目的 GitHub Release 页面，不申请未知来源安装权限，也不会静默安装。

## 安装

在下方 Assets 中下载 `wordbook-0.4.3.apk`。该安装包与 v0.4.1 使用相同签名，
可直接覆盖安装并保留生词、分册、批注和搜索历史。
